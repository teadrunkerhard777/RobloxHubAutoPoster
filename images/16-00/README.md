# Картинки для поста в 16:00

Добавляйте сюда изображения в форматах JPG, JPEG, PNG или WEBP.
Можно создавать вложенные папки — они тоже будут просканированы.

Каждый день скрипт случайно выбирает одну ещё не использованную картинку.
Когда будут использованы все картинки, начнётся новый цикл без повторов.

Рекомендуемый формат для Telegram: JPG, соотношение сторон 4:5 или 1:1,
размер файла до 10 МБ.
